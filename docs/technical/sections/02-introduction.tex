\subsection{Problemstellung}
Das Projekt MumbleMates ist nicht eine Lösung eines Problems, sondern eher ein Learning von Go, P2P und Terminal UI. Ziel des Projekts ist, die Grundlagen von Go zu erlernen und eine erste Version eines P2P Chats zu erstellen. 

und mit Go durfte bereits während dem Unterricht einige Erfahrungen mit Tutorials gesammelt werden. Mit LaTeX haben beide Autoren keine Erfahrungen.
\newline

Der gesamte technische Bericht wird in LaTeX dokumentiert.


\subsection{Ziele}

Folgende Ziele sind für das Projekt definiert:

\subsubsection{Go}
\begin{itemize}
    \item Wir beherrschen die Grundlagen von Go und könne auch komplexere Konzepte wie Go-Routines verstehen und anwenden.
    \item Wir erstellen ein P2P Chat in Go, welches sich auf das lokale Netzwerk beschränkt.
    \item Das Ergebnis ist eine ausführbare Applikation für Windows.
    \item Eine funktionierende Erstversion soll innerhalb der ersten zwei Wochen entstehen.
\end{itemize}

\subsubsection{LaTeX}

\begin{itemize}
    \item Die gesamte technische Dokumentation wird in LaTeX geschrieben und mit Git versioniert und als PDF-Datei bereitgestellt.
    \item Für die Kollaboration soll die Einrichtung von LaTeX möglichst einfach gehalten werden.
    \item LaTeX soll so funktionieren, dass es auch in zukünftigen Projekten verwendet werden kann.
    \item Eine erste Version soll innerhalb der ersten Woche stehen und auf der Plattform GitHub bereitgestellt werden.
\end{itemize}
